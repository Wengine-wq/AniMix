# AniPulse — ваша аниме-неделя

Персональный выпуск по коллекции: серии за неделю, новости и анонсы Shikimori, подтверждённые веб-новости за последние семь дней, факты о создании и ближайшие события. Основа выпуска — Shikimori (бесплатно, с датами), ИИ-обзор добавляется поверх, когда на устройстве есть доступ. Вход на главной показывает состояние выпуска недели. Вход — одна строка на главной после фильтров, дополнительный — в настройках коллекции. Чтение на отдельной странице; `animix://anipulse` открывает её напрямую.

## Персонализация и выпуски

- Экспериментальная функция: включается в «Настройки → Экспериментальные функции», по умолчанию выключена. Архив выпусков при выключении сохраняется.
- Внутри каждого списка в выпуск в первую очередь попадают онгоинги и анонсы: у них есть что рассказать за неделю.
- До четырёх тайтлов: в первую очередь «Смотрю», избранное и планы, с местом для уже просмотренного аниме. Брошенное исключается. Фактические тайтлы видны перед сборкой.
- Сборка начинается явной кнопкой. Устройство отправляет в Polza названия, статус списка и число просмотренных серий, а также публичные метаданные каталога. Имя пользователя, фото, отзывы, оценки, токены аккаунтов и файлы не отправляются. Об этом сказано до первого запроса.
- Идентификатор выпуска — неделя с понедельника по UTC. Новостное окно — семь суток перед началом сборки. Прогноз — следующие семь суток. Готовый выпуск сохраняет свой период; не меняется задним числом.
- Один готовый выпуск на неделю. Повторные нажатия объединены, повторное открытие не запускает ИИ. Выпуск, собранный без ИИ-обзора (нет доступа, лимит, сбой), помечен `aiEdited = false` с причиной в `note` и может быть собран заново в ту же неделю: обращения к Shikimori бесплатны. Запрос продолжается при уходе со страницы.
- Архив из последних 12 выпусков хранится в `anipulse.json` рядом с библиотекой, доступен без сети. Новый сбой не удаляет предыдущие выпуски; нечитабельный архив не перезаписывается пустым.
- До сервера новый выпуск собирается по кнопке. Фоновая доставка и пуши не реализованы. Цена показана как будущий план — 50 ₽/месяц; в раннем доступе оплаты и списаний с пользователя нет.

## Источники и точность

1. Для каждого тайтла и до двух связанных тайтлов в статусе анонса или онгоинга прочитать новости Shikimori: события (`/api/animes/:id/topics`: anons, ongoing, released, episode) и написанные новости (`/api/topics?forum=news&linked_type=Anime&linked_id=…`). Запросы последовательные, с паузой, из-за лимита Shikimori; сбой одного тайтла не мешает остальным. Дата берётся из `created_at` топика. Вышедшие за период серии собственного тайтла показываются в строке тайтла («за неделю +N»), анонс/старт/завершение — короткими материалами без ИИ. Написанные новости передаются редактору как источники `K…` с проверенной датой; если ИИ недоступен или их не пересказал — показываются заголовком и началом текста со ссылкой на Shikimori.
2. Обновить публичные карточки выбранных релизов. Для Shikimori используется прямой live-запрос, без подмены сохранёнными данными при сбое. При недоступности данные помечены сохранёнными. Первая цифра доступных серий не выдаётся за недельную прибавку; изменение считается относительно близкого предыдущего выпуска.
3. Выполнить до четырёх поисков через Polza `plugins.web`, отдельно для каждого тайтла. Поиск ориентирован на официальные японские сайты и редакционные аниме-издания. Перепосты из социальных сетей и страницы-индексы отбрасываются. Сбой одного поиска не прерывает выпуск; отказ ключа или лимита (401/402/403/429) прекращает платные вызовы этого запуска.
4. Передать редактору только аннотации поиска и новости Shikimori с дословными выдержками и проверенные публичные метаданные, а не сгенерированный исследователем пересказ. Каждая статья содержит ключ тайтла, известные ID источников и точную цитату из выдержки. Придуманные ссылки и отсутствующие цитаты отбрасываются.
5. Дату новости надо найти в URL/тексте источника или взять из проверенной даты источника Shikimori; дату будущего события — в самом тексте. Дата, придуманная моделью, не делает старую новость свежей. Проверяется существование календарной даты и диапазон выпуска.
6. Карточки каталога не превращаются в «факты»: они повторяют страницу тайтла. Дополнительная недорогая проверка отклоняет неподтверждённые детали внешних материалов и временные противоречия.
7. Если ИИ-обзор не дал материалов, заголовок и вступление пишет код по фактам выпуска (число серий и событий). Не утверждает, что во всей франшизе ничего не происходило. Если нет ни материалов, ни онгоингов в выпуске, сохраняется предыдущий выпуск и показывается понятная ошибка.

Это уменьшает ошибки, но не гарантирует безошибочность ИИ и поисковых выдержек. У каждого пункта остаются видимые ссылки, внизу — указание на ИИ-подготовку и необходимость проверить важные объявления. Сюжетные спойлеры запрещены в редакторском запросе. Веб-страницы и названия трактуются как данные, а не команды.

## Бюджет

- Основная модель: `openai/gpt-4o-mini`. Для короткой проверки фактов: `google/gemini-2.5-flash`; дорогие reasoning-модели не используются.
- Максимум четыре поисковых POST по 1100 выходных токенов, редактор до 3200, проверка до 1200. Источники и их текст ограничены. `usage.cost_rub` всех вызовов суммируется в `generationCostRub`, если провайдер вернул стоимость каждого вызова.
- У платных POST отсутствуют автоматические HTTP-повторы. Ошибка 401/402/429 обрабатывается без печати тела ответа и заголовков. Повтор после ошибки — явное действие пользователя; неудачные попытки также могут расходовать баланс Polza.
- Цена 50 ₽ — продуктовый план, не доказанная маржинальность. До платного запуска нужны серверные квоты, контроль пользователей, стоимости поиска, повторов, оплаты и срока подписки. Локальный кэш не заменяет серверный лимит расходов.

## Подключение без сервера

Общий ключ никогда не встраивается в APK, EXE, исходники, ресурсы и документы. Авторизованный ключ для этой разработки установлен локально на Windows, вне репозитория, с доступом текущего пользователя.

- Windows: `ANIMIX_POLZA_API_KEY` либо путь `ANIMIX_POLZA_KEY_FILE`, либо `%LOCALAPPDATA%/AniMix3/private/polza.key`. При `ANIMIX_HOME` путь по умолчанию находится в `private/polza.key` выбранной копии.
- Android: закрытый файл `noBackupFilesDir/polza.key`. Он не попадает в резервную копию приложения. Для установленной debug-сборки: `powershell -File scripts/connect-anipulse-preview.ps1`. Скрипт передаёт локальный ключ через stdin adb, без записи в аргументы команды и без вывода ключа. При нескольких устройствах нужен `-Serial`.
- Устройства без локального доступа собирают выпуск из Shikimori без ИИ-обзора и прямо пишут об этом в выпуске. Распространяемый APK общего ключа не содержит. Это ограничение клиентского прототипа до собственного сервера.

Ключи и архивы не должны попадать в тестовые фикстуры репозитория. Для локальных снимков используется изолированный `ANIMIX_HOME`; доступ к API передаётся путём к закрытому файлу.
