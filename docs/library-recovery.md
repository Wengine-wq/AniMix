# Сохранность локальной библиотеки

`library.json` читается с различением отсутствующего файла и ошибки чтения/формата. Ошибка больше не создаёт пустую библиотеку. Пока загрузка не завершилась успешно, запись библиотеки запрещена, включая сохранение при закрытии приложения.

Перед записью изменённого состояния предыдущий успешно прочитанный/сохранённый снимок атомарно записывается в `library.backup.json`. Повторный flush без изменений не заменяет полезную предыдущую копию текущим состоянием.

Если основной файл несовместим или отсутствует, используется исправная резервная копия. Несовместимый основной файл сначала сохраняется как `library.recovery-<timestamp>.json`; если сохранить его не удалось, замена не производится. Эти файлы находятся рядом с библиотекой, в каталоге данных AniMix (Windows по умолчанию: `%LOCALAPPDATA%/AniMix3/data`).

Если прочитать библиотеку и резервную копию не удалось, приложение показывает ошибку с повтором. Исходник не изменяется. Для ручного восстановления нужно закрыть приложение, сохранить отдельную копию исходника и поместить исправный `library.json` или `library.backup.json` в каталог данных. При повторной загрузке используется тот же экземпляр хранилища; перезапуск для повторной попытки не обязателен.

Общая инициализация показывает ошибку и для других повреждённых хранилищ. Автоматический сброс настроек или достижений не выполняется. При неуспешном запуске общее сохранение на выходе пропускается: значения по умолчанию незагруженных подсистем не записываются поверх файлов. При успешном запуске ошибка flush одной подсистемы регистрируется отдельно и не мешает остальным сохранить данные и приложению закрыться.

Проверки: `LibraryRecoveryTest`, тесты профиля/достижений и повторные UI-прогоны в `build/user-audit-fixes-2026-10-22`. Повреждение в проверках намеренное; это не оценка вероятности повреждения в реальном использовании.
