# Обновления через GitHub Releases

- Источник — один параметр `UpdateSource.REPOSITORY` (сейчас `Wengine-wq/AniMix`). Приложение раз в шесть часов (не чаще) читает `https://api.github.com/repos/<REPOSITORY>/releases`; ошибки сети тихие, проверка повторится позже.
- Учитываются только опубликованные релизы этой линии (не черновики и не pre-release) с тегом `v<версия>-re`, например `v1.0.6-re`. Релизы 2.x в том же репозитории (`v2.5.33`) никогда не предлагаются. Версия сравнивается с `AppRelease.build` по числам.
- Файлы берутся только по ссылкам `https://github.com/…`:
  - Android — APK для ABI устройства (`…arm64-v8a.apk` и т. п.), иначе `…universal.apk`, иначе единственный APK. Файл скачивается в `cache/updates` и передаётся системному установщику через `FileProvider`. Если установка из AniMix не разрешена, открывается системная настройка, а скачанный файл сохраняется для повторного нажатия. APK должен быть подписан тем же ключом, что и установленная версия.
  - Windows — `.msi`, иначе `.exe`, иначе `.zip`. Установщик запускается сразу. Архив (`AniMix-<версия>-re-Windows-x64.zip`, внутри папка `AniMix` с `AniMix.exe`) распаковывается рядом с загрузкой, а скрипт PowerShell ждёт закрытия AniMix, копирует новые файлы в папку запущенного `AniMix.exe` (`jpackage.app-path`) и запускает его снова. Данные в `%LOCALAPPDATA%\AniMix3` не затрагиваются.
- Раз за запуск поверх приложения — окно обновления (с 1.2.2 re): значок приложения, «Доступно обновление · AniMix X re», установленная версия и размер файла, короткая рекомендация обновиться (если пропущено несколько релизов этой линии — сколько, `AvailableUpdate.behind`), «Что изменилось», что произойдёт при установке на этой платформе, одна главная кнопка «Обновить сейчас» и тихое «Напомнить при следующем запуске». До следующего запуска обновление ждёт в «Настройках». «Что изменилось» — первый маркированный список в описании релиза, поэтому описание начинается со списка изменений по сравнению с предыдущей версией (тот же текст, что `AppRelease.changes`), а установка и контрольные суммы идут ниже. «Позже» скрывает эту версию; более новая будет предложена снова.

## Как выпустить версию

1. Поднять `versionName`/`versionCode` (Android), `packageVersion` (Windows) и `AppRelease.build`.
2. `gradlew :androidApp:assembleRelease :desktopApp:createReleaseDistributable` — APK подписывается ключом из `%USERPROFILE%\.animix\release.properties` (`release.jks`). Без этого ключа обновления на Android невозможны: установленная копия примет только APK с той же подписью.
3. Создать релиз в `Wengine-wq/AniMix` с тегом `v<build>-re`: `AniMix-<build>-re-universal.apk`, `AniMix-<build>-re-Windows-x64.zip` (папка `AniMix` из `desktopApp/build/compose/binaries/main-release/app`) и `SHA256SUMS.txt`.

## Android: идентификатор и ключ

Релиз — `app.animix.newhorizons`, отдельно от AniMix 2.x (`com.example.animix`). 2.x подписывался отладочным ключом, которого больше нет, поэтому New Horizons не может обновить 2.x и ставится рядом. Перенос локального профиля 2.x на телефоне при этом недоступен: списки переносятся с ПК или через онлайн-профиль.

## История версий

- **1.2.2 re «Fine Tuning»** (ноябрь 2026): AniPulse как выпуск — вступление, главная история и пересказы новостей без ИИ; перерисованные и заметные оформления и рамки профиля с лёгким движением; счётчик уведомлений на кнопке «Меню» вместо колокольчика; шестерёнка плеера без пустого списка, скорость и свайпы яркости и громкости в обоих плеерах; настоящие аватарки в «Друзьях»; новое окно обновления (зачем обновляться, сколько версий пропущено, что произойдёт); перенос из AniMix 2.x в «Импорте списков»; «О приложении» без плана развития. Сервер не менялся.

- **1.2.1 re «Solid Ground»** (ноябрь 2026): надёжные награды за сезоны и фильмы при неточных таймингах эндинга, темы Horizon Noon (5-й уровень) и Horizon Midnight (10-й) и четыре значка приложения, кнопка пропуска с 10-секундной заливкой, рабочая «картинка в картинке», единый отклик нажатий, AniPulse как дайджест недели, постоянная полка «Подобрано для вас» и подборки вне экспериментов, профиль друга как свой, страницы студий, примерка наград профиля, шлюз запросов к Shikimori. На Android значок приложения переехал в `activity-alias`: после обновления значок на рабочем столе может понадобиться добавить заново.

- **1.2.0 re «Make it yours»** (ноябрь 2026): «Плеер+» и «Упрощённый» плеер, уведомления о новых сериях и о серии в выбранной озвучке, награды за уровни (оформление профиля на 10-м, рамка на 20-м), AniPulse без ИИ, свои подборки и умный подбор (экспериментально), профиль друга с коллекцией и достижениями, приватность по разделам, имена и отключение устройств, меню карточками, новый маскот. Исправлены потеря гостевого просмотра при входе и мигание рамок плеера на паузе. Сервер: один запрос присутствия вместо четырёх, сжатие ответов, проверка ревизии без скачивания коллекции, кэш сессий.
- **1.1.1 re «Improved user experience»** (1 ноября 2026): производительность плеера, пропуски по соседним сериям, «Связанное» и «Похожее», диалог обновления, плашки профиля.
- **1.1.0 re «MORE than just a bug fix»** (1 ноября 2026): друзья в сети, Horizon Link, синхронизация аккаунта.
