# Миграция с AniMix 2.x

«Настройки → Аккаунт → Миграция с AniMix 2.x» переносит данные прежней версии: списки и оценки, просмотренные серии, часы просмотра, достижения, которые есть в текущей версии, и имя профиля.

## Источники

- **Аккаунт AniMix 2.x.** Вход через Google на сервере 2.x (`/v1/auth/google/start` → `animix://oauth/callback` → `/v1/auth/google/exchange`). Читаются `/v1/library`, `/v1/usage` и `/v1/me/achievements`, затем сессия закрывается (`/v1/auth/logout`). Токены не сохраняются. Ответ входа принимается только в течение 15 минут после нажатия «Войти» на этом устройстве.
  - Android: страница входа открывается в браузере (Google не пускает вход во встроенный WebView), ответ возвращается ссылкой `animix://oauth/callback`; `MainActivity` в режиме `singleTask` передаёт её миграции, не открывая новый экран.
  - Windows: отдельное окно Edge/Chrome со своим профилем, как вход в Shikimori. Переход на `animix://` не становится адресом вкладки, поэтому он читается из сетевых событий DevTools этого окна.
- **Этот компьютер (Windows).** Файл `%APPDATA%/com.example/animix/shared_preferences.json` прежней версии: кэш списка аккаунта и локальный профиль без аккаунта (новая запись побеждает), награды `local_achievements_v1_*`, дневные секунды `usage_seconds_v1_*`, отмеченные серии `watched_eps_v2_*`. Копия с `ANIMIX_HOME` читает только `<ANIMIX_HOME>/legacy/shared_preferences.json`.
- На Android данные 2.x без аккаунта закрыты внутри прежнего приложения, поэтому на телефоне перенос идёт через аккаунт.

## Что и как переносится

- Тайтлы загружаются из Shikimori пачками по 50 ID и импортируются как история просмотров: статус и оценка с этого устройства сохраняются, просмотренных серий становится только больше. Это история, а не подтверждённый просмотр AniMix: XP за серии и минуты не начисляется. Отмеченные в 2.x серии учитываются непрерывным префиксом от первой серии.
- Часы просмотра хранятся отдельно (`legacyWatchSeconds`) и входят в «часов в AniMix» и в награды за время. Не больше 24 часов в сутки там, где известны дни; повторный перенос берёт максимум, а не сумму.
- Награды 2.x, существующие в текущей версии, становятся обычными наградами с датой из 2.x и обычными 50 XP каждая: `download` → «Интернет переоценён», `completed` → «Ну всё, теперь можно жить», `marathon` → «Воу воу куда так быстро», `insane` (сутки просмотра) → «Это всё ещё одна серия», `titan_wall` → «За стеной спойлеры», `demon_blade` → «Дыхание автоплея», `one_piece` → «Ещё 1000 серий и спать». Остальные награды 2.x не имеют пары и не переносятся.
- Имя профиля берётся из 2.x, только если сейчас стоит имя по умолчанию.
- Достижение «Новый AniMix — а списки-то старые» выдаётся один раз за вход в аккаунт 2.x (вариант «вход») или за регистрацию онлайн-профиля — первый вход Google, при котором сервер создал профиль (вариант «регистрация»). Перенос с компьютера без аккаунта его не даёт.
