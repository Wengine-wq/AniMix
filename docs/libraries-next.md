# Библиотеки для AniMix: что имеет смысл добавить

Проверено по официальной документации и репозиториям 22 октября 2026. Целевые платформы проекта: Android и JVM Desktop (Windows), Kotlin 2.4.21, Compose Multiplatform 1.12.2. Kermit 2.2.0 (включая kermit-io), DataStore Preferences 1.3.0 и Reorderable 3.1.0 уже подключены и используются. Android и Windows проходят сборку; Room и Compose Shimmer остаются кандидатами. Поддержка платформы не заменяет проверку конкретной версии с нашим Gradle и Compose.

| Приоритет | Библиотека | Задача в AniMix | Что учитывать |
| --- | --- | --- | --- |
| 1 | [Kermit](https://kermit.touchlab.co/docs/) | Общие диагностические сообщения для сохранений, импорта, загрузок и плеера. Ошибки прежних best-effort сохранений теперь попадают в журнал. | Теги и уровни настроены; локальный журнал ротируется по 256 KiB, до трёх файлов. Не писать токены, подписанные URL и содержимое личных списков. Облачный сбор сам по себе не требуется. |
| 2 | [Reorderable](https://github.com/Calvin-LL/Reorderable) | Перестановка серий в очереди Watch flow мышью и долгим нажатием. | Поддерживает Android и Desktop/JVM, списки и сетки, автопрокрутку у края. Сохранить доступные кнопки перемещения, фиксировать порядок только через модель очереди, учитывать запрет изменения текущей сессии. Подключена версия 3.1.0; проверены мышь и touch-события в desktop-рендерере. |
| 3 | [Room + SQLite](https://developer.android.com/kotlin/multiplatform/room) | Библиотека, история просмотра, достижения и очередь будущей синхронизации в транзакционном хранилище. | Поддерживает Android и JVM Desktop. Текущий пример документации использует Room 3.1 alpha: не копировать его версию автоматически в стабильный релиз. Выбирать стабильную ветку после проверки актуальных релизов и KSP. |

Одноразовая миграция `settings.json` реализована; оригинал остаётся резервной копией. Не использовать вместо базы больших списков и покрытия просмотренных серий. |

README сопоставляет 1.5.0 с Compose 1.11, а у нас 1.12.2 — требуется проверка. В текущей правке общий эффект уже реализован на Compose с отключением анимации и чтением фазы при рисовании; отдельная зависимость сейчас не нужна. |

## Рекомендуемый порядок

Kermit уже пишет события хранения, загрузок, импорта, сетевой загрузки экранов и ошибок нативного плеера. Reorderable управляет перестановкой черновика Watch flow. DataStore хранит небольшие настройки с одноразовым переносом JSON. Следующий отдельный этап — Room перед серверной синхронизацией с сохранением импорта старых данных и правил исторических наград без XP.

## Что уже есть

Coil отвечает за изображения и их кеш, Ktor — за HTTP, Haze — за стекло, Media3 и VLCJ — за воспроизведение. Дублирующие зависимости здесь не нужны. [Koin](https://insert-koin.io/docs/setup/) поддерживает KMP/Compose, но текущий `AppGraph` пока небольшой и явный; перенос на контейнер не устраняет наблюдаемую проблему сам по себе.

## Проверка внедрения

- Собрать Android и JVM Desktop с выбранной стабильной версией, проверить транзитивные версии Kotlin/Compose.
- Для хранилища проверить обновление существующего профиля, прерванную миграцию, повторный запуск и сохранность XP/исторических наград.
- Для Reorderable проверить мышь, касание, автопрокрутку, крупный шрифт, отключённые анимации и сохранение очереди после перезапуска.
- Для диагностики проверить отсутствие чувствительных данных в журнале и ограничить размер хранения.
