# AniMix project instructions

- Before any interface change, read [docs/interface-guidelines.md](docs/interface-guidelines.md). It records the user's product requirements for AniMix 3.0.
- Preserve one coherent interface across screens and platforms. Reuse the theme, components, spacing, shapes and motion rules instead of inventing screen-specific decoration.
- Use the Watch screen as the interaction reference for dubbing selection and episode navigation. Downloads use a full page with episode cards, not a bottom sheet or expandable episode list.
- Update the interface guidelines when the user changes a product-wide design decision.
- Before changing playback rewards, level calculations or power saving, read [docs/viewing-levels-power.md](docs/viewing-levels-power.md). Never derive watch achievements from seek position or manual list marks.
